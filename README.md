# 📘 CurriculumMD: คลังหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน (ฉบับสมบูรณ์ ๒,๐๒๔ ตัวชี้วัด)

> **CurriculumMD** คือ โครงการแปลงหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน พุทธศักราช ๒๕๕๑ (ฉบับปรับปรุง ๒๕๖๐ และประกาศตัวชี้วัดระหว่างทาง-ปลายทาง สพฐ. ๒๕๖๖) ให้อยู่ในรูปแบบ **Markdown Knowledge Vault** ที่มีความสมบูรณ์แบบ 100% พร้อมใช้งานบน **Obsidian**, Web Documentation (MkDocs), และระบบ AI Co-pilot

---

## 🌟 จุดเด่นของโครงการ (Highlights)

1. **ครบถ้วน 100% ตามประกาศ สพฐ. (๒๓ มิ.ย. ๒๕๖๖):** 
   - ตัวชี้วัดครบทั้ง **2,024 ตัวชี้วัด** (ระหว่างทาง 1,264 ตัวชี้วัด, ปลายทาง 760 ตัวชี้วัด, ไม่ระบุ 0 ตัวชี้วัด)
   - ครอบคลุมครบทั้ง 8 กลุ่มสาระการเรียนรู้ ตั้งแต่ชั้น ป.1 ถึง ม.6
2. **สาระการเรียนรู้แกนกลางแท้และสมบูรณ์:**
   - วิชาวิทยาศาสตร์และเทคโนโลยี และคณิตศาสตร์ ใช้เนื้อหาสาระแกนกลางตามหลักสูตรปรับปรุง พ.ศ. ๒๕๖๐ (สสวท.)
   - วิชาภาษาไทย, สุขศึกษาและพลศึกษา, ศิลปะ, การงานอาชีพ และภาษาต่างประเทศ ถอดรหัสฟอนต์ MacThai (PSL-Kittithada) คืนสู่อักขระภาษาไทยและวรรณยุกต์มาตรฐาน 100%
3. **โครงข่ายความรู้แบบ Bidirectional Links (`[[...]]`):**
   - มีระบบ Navigation Index files 98 ไฟล์ เชื่อมโยงระดับ วิชา -> สาระ -> มาตรฐาน -> ตัวชี้วัด
   - เชื่อมโยงคำสำคัญทางการศึกษา (Cross-Discipline Educational Concepts) ข้ามกลุ่มสาระการเรียนรู้ เช่น `[[แนวคิดเชิงคำนวณ]]`, `[[ระบบนิเวศ]]`, `[[อัตราส่วน]]`, `[[สมการ]]`
4. **พร้อมต่อยอดสู่ AI & โรงเรียน:**
   - โครงสร้าง YAML Frontmatter มาตรฐาน พร้อมรัน Dataview Query และ Vector Search (RAG)
   - รองรับการเชื่อมโยงกับ "หลักสูตรสถานศึกษา" และ "หน่วยการเรียนรู้รายวิชา"

## 🚀 วิธีการใช้งาน

### 1. เปิดใช้งานใน Obsidian
1. ดาวน์โหลดหรือโคลน (Clone) คลังข้อมูลนี้ลงในเครื่อง
2. เปิดโปรแกรม **Obsidian**
3. เลือก **"Open folder as vault"**
4. เลือกโฟลเดอร์ `Curriculum_Vault`
5. เริ่มต้นสำรวจจากไฟล์ `00_หลักสูตรแกนกลาง.md` หรือเปิดมุมมอง **Graph View** เพื่อดูเครือข่ายความสัมพันธ์

### 2. ตรวจสอบความถูกต้องของข้อมูล (Audit Verification)
สามารถรันสคริปต์เพื่อตรวจสอบจำนวนตัวชี้วัดและประเภทระหว่างทาง/ปลายทางได้ทันที:
```bash
python audit_vault.py
```
