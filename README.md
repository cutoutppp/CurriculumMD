## ทำไมต้องมีโปรเจกต์นี้

หลักสูตรแกนกลางเผยแพร่เป็นไฟล์ PDF เป็นหลัก และข้อความภาษาไทยที่คัดลอกออกมาจาก PDF มักเพี้ยน
- สระและวรรณยุกต์สลับที่ เช่น `อธบิ าย` แทน `อธิบาย`
- มีช่องว่างแทรกกลางคำ
- ข้อความจากคอลัมน์ข้างเคียงในตารางไหลมาปนกับข้อนี้

ครูที่ต้องใช้ตัวชี้วัดในแผนการสอน แบบ วผ. หรือระบบสารสนเทศ ต้องพิมพ์ใหม่เองหรือแก้ทีละข้อ โปรเจกต์นี้รวบรวมตัวชี้วัดทั้งหมดไว้ที่เดียว แก้ข้อความให้ถูกต้อง และตรวจเทียบกับหลายแหล่งแล้ว

## ตรวจความถูกต้องอย่างไร

ข้อความทุกข้อเทียบกับแหล่งที่ไม่ได้ดึงข้อความมาจาก PDF อย่างน้อย 2 แหล่ง

| แหล่ง | ครอบคลุม |
| :--- | :--- |
| ไฟล์ Word ต้นฉบับ สพฐ. ชุดตัวชี้วัดระหว่างทาง/ปลายทาง (เม.ย.–ก.ค. ๒๕๖๖) | ทุกกลุ่มสาระ ทุกชั้น |
| เล่มหลักสูตร ๒๕๕๑ ฉบับ Word | ภาษาไทย สังคมฯ สุขศึกษาฯ ศิลปะ การงานฯ ภาษาต่างประเทศ |
| OCR จากภาพหน้า PDF ด้วย [Typhoon OCR](https://huggingface.co/typhoon-ai/typhoon-ocr1.5-2b) | ข้อที่สงสัย และวิทยาศาสตร์ ม.4–6 |
| แผนการสอน DLTV (HTML) | ป.1–ม.3 โดยเฉพาะคณิตศาสตร์ วิทยาศาสตร์ และสังคมฯ |
| เอกสารคณิตศาสตร์ ๒๕๖๐ ของโรงเรียน (Google Docs) | คณิตศาสตร์ ม.1–6 |

**หลักการแก้ข้อความ**
- เมื่อแหล่งไม่ตรงกัน ให้ยึดถ้อยคำตามเล่ม สพฐ. ๒๕๖๖
- คำที่พิมพ์ผิดในต้นฉบับ สพฐ. เอง (เช่น `เหมาะะสม` และ `ปรียบเทียบ`) แก้ให้ถูกต้อง
- ข้อความที่ไหลมาจากคอลัมน์ข้างเคียงในตาราง ย้ายกลับไปไว้ในข้อที่ถูกต้อง
- ข้อสังเกต: ในเล่ม ๒๕๖๖ ตัวชี้วัด ส 4.1 ที่เกี่ยวกับวิธีการทางประวัติศาสตร์มีเครื่องหมาย `*` นำหน้า คลังนี้ไม่ได้ใส่ `*` ไว้ในข้อความ

**ตรวจโครงสร้างด้วยสคริปต์ 3 ชั้น**

```bash
python audit_vault.py        # schema frontmatter, รหัสไม่ซ้ำ, ลิงก์ไม่ขาด
python audit_vault_tier3.py  # ความสัมพันธ์ ตัวชี้วัด → มาตรฐาน → สาระ และอัปเดตตารางด้านบน
```

พบข้อความผิดพลาด? เปิด [Issue](https://github.com/cutoutppp/CurriculumMD/issues) พร้อมรหัสตัวชี้วัดและเลขหน้าในเอกสาร สพฐ.

## เริ่มใช้งาน

**ใช้ใน Obsidian**
1. Clone หรือดาวน์โหลด repo นี้
2. ใน Obsidian เลือก **Open folder as vault**
3. เลือกโฟลเดอร์ `Curriculum_Vault`
4. เริ่มดูจาก `00_หลักสูตรแกนกลาง.md` หรือเปิด Graph View

**ใช้ข้อมูลในโปรแกรมของคุณเอง**

```python
import json
kpis = json.load(open('all_kpi_master.json', encoding='utf-8'))
m1_sci = [k for k in kpis.values() if k['subject'].startswith('วิทยาศาสตร์') and k['grade'] == 'ม.1']
```

**ผู้ช่วยร่างแผนการสอน**

```bash
python ai_assistant.py
```

## แหล่งอ้างอิงทางการ

- ประกาศสำนักงานคณะกรรมการการศึกษาขั้นพื้นฐาน เรื่อง การกำหนดตัวชี้วัดระหว่างทางและตัวชี้วัดปลายทาง ตามหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน พุทธศักราช ๒๕๕๑ (๒๓ มิถุนายน ๒๕๖๖)
- มาตรฐานการเรียนรู้และตัวชี้วัด กลุ่มสาระการเรียนรู้คณิตศาสตร์ วิทยาศาสตร์ และสาระภูมิศาสตร์ (ฉบับปรับปรุง พ.ศ. ๒๕๖๐)
- ตัวชี้วัดและสาระการเรียนรู้แกนกลาง ตามหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน พุทธศักราช ๒๕๕๑

> ⚠️ คลังนี้จัดทำเพื่อสนับสนุนการสอน การวิจัย และการพัฒนาเครื่องมือการศึกษา ไม่ใช่เอกสารทางการของ สพฐ. หากใช้อ้างอิงในเอกสารราชการ โปรดตรวจกับต้นฉบับของ สพฐ. อีกครั้ง
