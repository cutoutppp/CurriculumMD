# 📘 CurriculumMD: คลังหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน (ฉบับสมบูรณ์ ๒,๐๕๖ ตัวชี้วัด)

> **CurriculumMD** คือ โครงการแปลงหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน พุทธศักราช ๒๕๕๑ (ฉบับปรับปรุง พ.ศ. ๒๕๖๐ และประกาศตัวชี้วัดระหว่างทาง-ปลายทาง สพฐ. ๒๕๖๖) ให้อยู่ในรูปแบบ **Markdown Knowledge Vault** พร้อมระบบตรวจสอบย้อนกลับ 3 ชั้น (3-Tier Audit) พร้อมใช้งานบน **Obsidian**, Web Documentation (MkDocs), และระบบ AI Co-pilot

---

## 🌟 จุดเด่นของโครงการ (Highlights)

1. **ครบถ้วน 2,056 ตัวชี้วัดตามประกาศ สพฐ. (๒๓ มิ.ย. ๒๕๖๖):** 
   - ตัวชี้วัดแกนกลางครบทั้ง **2,056 ตัวชี้วัด** (ระหว่างทาง 1,285 ตัวชี้วัด, ปลายทาง 771 ตัวชี้วัด, ไม่ระบุประเภท 0 ตัวชี้วัด)
   - ครอบคลุมครบทั้ง 8 กลุ่มสาระการเรียนรู้ ตั้งแต่ชั้น ป.1 ถึง ม.6
   - รวมสาระที่ 5 ภูมิศาสตร์ (ส 5.1 และ ส 5.2) ครบทั้ง 66 ตัวชี้วัดตามฉบับปรับปรุง พ.ศ. ๒๕๖๐
2. **ระบบตรวจสอบความถูกต้อง 3 ชั้น (3-Tier Verification System):**
   - **ชั้นที่ 1 (Structural Integrity):** ตรวจสอบ schema frontmatter, รหัสเฉพาะ (Unique IDs ไม่ซ้ำ), ลิงก์มาตรฐาน (`belongs_to`) ครบถ้วน 100%
   - **ชั้นที่ 2 (Ground-Truth Fidelity):** ตรวจสอบเลขหน้าสาระการเรียนรู้แกนกลาง และเนื้อหาสาระแกนกลางตรงตามเอกสารทางการ สพฐ. 100%
   - **ชั้นที่ 3 (Relational Mapping):** ตรวจสอบโครงสร้างความสัมพันธ์ระหว่างตัวชี้วัด สาระ และมาตรฐานการเรียนรู้ (`belongs_to`) ครบถ้วน 100%
3. **สาระการเรียนรู้แกนกลางแท้และสมบูรณ์:**
   - วิชาวิทยาศาสตร์และเทคโนโลยี คณิตศาสตร์ และสาระภูมิศาสตร์ ใช้เนื้อหาสาระแกนกลางตามหลักสูตรปรับปรุง พ.ศ. ๒๕๖๐ (สสวท.)
   - วิชาภาษาไทย สุขศึกษาและพลศึกษา ศิลปะ การงานอาชีพ และภาษาต่างประเทศ คืนค่าอักขระและวรรณยุกต์มาตรฐาน UTF-8
   - บูรณะคำอธิบายตัวชี้วัดที่ตกหล่นและสลับวรรณยุกต์ตรงตามเอกสารแม่แบบของ สพฐ. 100%
4. **โครงข่ายความรู้แบบ Bidirectional Links (`[[...]]`):**
   - ระบบ Navigation Index files 96 ไฟล์ เชื่อมโยงระดับ วิชา -> สาระ -> มาตรฐาน -> ตัวชี้วัด
   - เชื่อมโยงคำสำคัญทางการศึกษา (Cross-Discipline Educational Concepts) ข้ามกลุ่มสาระการเรียนรู้
5. **พร้อมต่อยอดสู่ AI & โรงเรียน:**
   - โครงสร้าง YAML Frontmatter มาตรฐาน พร้อมรัน Dataview Query และ Vector Search (RAG)
   - มาพร้อม `ai_assistant.py` สำหรับสืบค้นตัวชี้วัดและร่างแผนการสอน Active Learning

## 🚀 วิธีการใช้งาน

### 1. เปิดใช้งานใน Obsidian
1. ดาวน์โหลดหรือโคลน (Clone) คลังข้อมูลนี้ลงในเครื่อง
2. เปิดโปรแกรม **Obsidian**
3. เลือก **"Open folder as vault"**
4. เลือกโฟลเดอร์ `Curriculum_Vault`
5. เริ่มต้นสำรวจจากไฟล์ `00_หลักสูตรแกนกลาง.md` หรือเปิดมุมมอง **Graph View** เพื่อดูเครือข่ายความสัมพันธ์

### 2. ตรวจสอบความถูกต้องของข้อมูล (Audit Verification)
สามารถรันสคริปต์เพื่อตรวจสอบความถูกต้องทั้ง 3 ชั้นได้ทันที (ใช้ Path สัมพัทธ์ รันได้ทุกสภาพแวดล้อม):
```bash
# ตรวจสอบสถิติภาพรวม
python audit_vault.py

# ตรวจสอบความสมบูรณ์ 3 ชั้น (โครงสร้าง, เลขหน้า, ความตรงกับต้นฉบับ)
python audit_vault_tier3.py
```

### 3. ใช้งาน AI Curriculum Assistant (ผู้ช่วยออกแบบแผนการสอน)
```bash
python ai_assistant.py
```
ระบุหัวข้อที่ต้องการสอนและระดับชั้น (เช่น แผนที่ ป.4 หรือ เซลล์ ม.1) ระบบจะดึงตัวชี้วัดทางการ สาระแกนกลาง พร้อมร่าง Prompt แผนการจัดการเรียนรู้ Active Learning ให้อัตโนมัติ
