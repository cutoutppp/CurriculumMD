# ว 3.1 ป.3/3

> ตระหนักถึงความสำคัญของดวงอาทิตย์ โดยบรรยายประโยชน์ของดวงอาทิตย์ต่อ[[สิ่งมีชีวิต]]

**วิชา:** วิทยาศาสตร์และเทคโนโลยี
**สาระ:** [[00_สาระที่ 3 วิทยาศาสตร์โลก และอวกาศ|สาระที่ 3 วิทยาศาสตร์โลก และอวกาศ]]
**มาตรฐาน:** [[00_มาตรฐาน ว 3.1|มาตรฐาน ว 3.1]] (เข้าใจองค์ประกอบ ลักษณะ กระบวนการเกิด และวิวัฒนาการของ[[เอกภพ]] กาแล็กซี ดาวฤกษ์ และ[[ระบบสุริยะ]] รวมทั้งปฏิสัมพันธ์ภายในระบบสุริยะที่ส่งผลต่อสิ่งมีชีวิต และการประยุกต์ใช้เทคโนโลยีอวกาศ)

**สาระการเรียนรู้แกนกลาง:**
- การหมุนรอบตัวเองของโลก ปรากฏการณ์กลางวันกลางคืน การขึ้นและตกของดวงอาทิตย์ ทิศ
