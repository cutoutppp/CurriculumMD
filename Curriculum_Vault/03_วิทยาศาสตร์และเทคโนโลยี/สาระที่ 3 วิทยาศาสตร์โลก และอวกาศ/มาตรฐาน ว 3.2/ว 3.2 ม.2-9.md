# ว 3.2 ม.2/9

> สร้างแบบจำลองที่ อธิบายการใช้น้ำ และนำเสนอ แนวทางการใช้น้ำอย่างยั่งยืน ในท้องถิ่นของตนเอง

**วิชา:** วิทยาศาสตร์และเทคโนโลยี
**สาระ:** [[00_สาระที่ 3 วิทยาศาสตร์โลก และอวกาศ|สาระที่ 3 วิทยาศาสตร์โลก และอวกาศ]]
**มาตรฐาน:** [[00_มาตรฐาน ว 3.2|มาตรฐาน ว 3.2]] (เข้าใจองค์ประกอบและความสัมพันธ์ของระบบโลก กระบวนการเปลี่ยนแปลงภายในโลกและบนผิวโลก ธรณีพิบัติภัย กระบวนการเปลี่ยนแปลงลมฟ้าอากาศและภูมิอากาศโลก รวมทั้งผลต่อ[[สิ่งมีชีวิต]]และสิ่งแวดล้อม)

**สาระการเรียนรู้แกนกลาง:**
- โครงสร้างโลกและกระบวนการเปลี่ยนแปลงบนผิวโลก: การผุพังอยู่กับที่ การกร่อน การพัดพา การสะสมตัวของตะกอน
- ดิน หิน แร่ เชื้อเพลิงซากดึกดำบรรพ์ (ปิโตรเลียม ถ่านหิน) และแหล่งน้ำ
