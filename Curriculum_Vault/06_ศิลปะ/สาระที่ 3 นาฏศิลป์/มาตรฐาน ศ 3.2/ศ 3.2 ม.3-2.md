# ศ 3.2 ม.3/2

> อธิบายความสำคัญ และบทบาทของ[[นาฏศิลป์]]และ การละครในชีวิตประจำวัน

**วิชา:** ศิลปะ
**สาระ:** [[00_สาระที่ 3 นาฏศิลป์|สาระที่ 3 นาฏศิลป์]]
**มาตรฐาน:** [[00_มาตรฐาน ศ 3.2|มาตรฐาน ศ 3.2]] (เข้าใจความสัมพันธ์ระหว่างนาฏศิลป์ ประวัติศาสตร์และวัฒนธรรม เห็นคุณค่าของนาฏศิลป์ที่เป็นมรดกทางวัฒนธรรม [[ภูมิปัญญาท้องถิ่น]] ภูมิปัญญาไทยและสากล)

**สาระการเรียนรู้แกนกลาง:**
- ความสำคัญและบทบาทของนาฏศิลป์ และการละครในชีวิตประจำวัน
