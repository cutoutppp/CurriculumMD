# ศ 3.2 ป.1/1

> ระบุ และเล่น การละเล่นของเด็กไทย

**วิชา:** ศิลปะ
**สาระ:** [[00_สาระที่ 3 นาฏศิลป์|สาระที่ 3 นาฏศิลป์]]
**มาตรฐาน:** [[00_มาตรฐาน ศ 3.2|มาตรฐาน ศ 3.2]] (เข้าใจความสัมพันธ์ระหว่าง[[นาฏศิลป์]] ประวัติศาสตร์และวัฒนธรรม เห็นคุณค่าของนาฏศิลป์ที่เป็นมรดกทางวัฒนธรรม [[ภูมิปัญญาท้องถิ่น]] ภูมิปัญญาไทยและสากล)

**สาระการเรียนรู้แกนกลาง:**
- การละเล่นของเด็กไทย
- วิธีการเล่น
- กติกา การแสดงนาฏศิลป์
