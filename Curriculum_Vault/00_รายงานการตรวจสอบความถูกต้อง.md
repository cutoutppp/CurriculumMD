## 🛠️ 3. การแก้ไขข้อผิดพลาดในการพิมพ์ของเอกสารทางการ (Document Normalization Log)

1. **การถอดรหัสฟอนต์ MacThai (Legacy 2551):** แปลงรหัสฟอนต์ MacThai ยุคเก่าในเล่มภาษาไทย, สุขศึกษา, ศิลปะ, การงานอาชีพ และภาษาต่างประเทศ ให้เป็นอักขระภาษาไทยและวรรณยุกต์มาตรฐาน UTF-8 100%
2. **การบูรณะตัวชี้วัดสาระภูมิศาสตร์ (ส 5.1 และ ส 5.2):** สกัดและจัดทำครบทั้ง 66 ตัวชี้วัด (ระหว่างทาง 37, ปลายทาง 29) ตามหลักสูตรฉบับปรับปรุง พ.ศ. ๒๕๖๐ พร้อมเนื้อหาสาระการเรียนรู้แกนกลางและเลขหน้าอ้างอิงตรงกับเอกสารทางการ
3. **การพิมพ์ตกหล่นและอักขระแยกส่วน (Typo Normalization):**
   - **ภาษาไทย (ป.2):** เอกสาร สพฐ. พิมพ์ผิดเป็น `ท 3.1 ป.3/4` ในตารางชั้น ป.2 ได้รับการปรับปรุงเป็น `ท 3.1 ป.2/4` ให้ถูกต้องตรงชั้นปี
   - **ภาษาต่างประเทศ (ป.5):** เอกสาร สพฐ. พิมพ์เครื่องหมายทับผิดที่ `ต 1.2 ป./ 55` ได้รับการแก้ไขเป็น `ต 1.2 ป.5/5`
   - **วิทยาศาสตร์และเทคโนโลยี (ม.2):** เอกสาร สพฐ. พิมพ์จุดซ้ำหลังมาตรฐาน `ว 1.2.` (ในตัวชี้วัด ม.2/3, ม.2/5, ม.2/9, ม.2/11) ย้ายเข้าโฟลเดอร์มาตรฐาน ว 1.2 ที่ถูกต้อง และลบโฟลเดอร์แปลกปลอมออก
   - **ศิลปะ:** เติมเต็มคำอธิบายตัวชี้วัด 11 ข้อที่ว่างเปล่า (ศ 2.1, ศ 3.1, ศ 3.2) ตรงตามเอกสารทางการ สพฐ. 100% พร้อมแก้ไขสระ/วรรณยุกต์กลับด้าน
   - **สังคมศึกษา (ม.3):** แก้ไขประเภทตัวชี้วัด `ส 1.1 ม.3/7` เป็น "ปลายทาง" และปรับแก้ประเภทตัวชี้วัดให้ตรงกับตารางคอลัมน์ สพฐ. ๒๕๖๖ ทั้งหมด 418 ตัวชี้วัด (ระหว่างทาง 278, ปลายทาง 140)
   - **การงานอาชีพ:** กำหนดโครงสร้างครอบคลุมทั้ง สาระที่ 1 (มาตรฐาน ง 1.1: 36 ตัวชี้วัด) และ สาระที่ 2 การอาชีพ (มาตรฐาน ง 2.1: 18 ตัวชี้วัด) รวมเป็น 54 ตัวชี้วัด

## 🔍 4. สถาปัตยกรรมการตรวจสอบความถูกต้อง 3 ชั้น (3-Tier Provenance Verification System)

ระบบตรวจสอบความถูกต้องได้รับการยกระดับตามมาตรฐาน **Data Provenance และ Automated Ground-Truth Verification** โดยแบ่งการประเมินออกเป็น 3 มิติอย่างโปร่งใส:

1. **ชั้นที่ 1: การตรวจสอบโครงสร้างและ Schema (Structural Integrity)**
   - ตรวจสอบความถูกต้องของ YAML Frontmatter ครบ 2,056 ไฟล์
   - รหัสประจำตัว (Unique IDs) ไม่ซ้ำซ้อน 2,056 รายการ
   - ลิงก์เชื่อมโยงมาตรฐานหลัก (`belongs_to`) เป็นฟิลด์บังคับ ห้ามว่าง และชี้ไปยังไฟล์มาตรฐานที่มีอยู่จริง 100%
   - ผลการประเมิน: **ผ่านเกณฑ์ 2,056 / 2,056 รายการ (100.0%)**

2. **ชั้นที่ 2: ความตรงกับเอกสารต้นฉบับ สพฐ. (Ground-Truth Automated Text Fidelity)**
   - ตรวจสอบการระบุเอกสารอ้างอิงและเลขหน้าต้นฉบับครบ 2,056 รายการ
   - ระบบ Automated Text Diff นำข้อความคำอธิบายตัวชี้วัด (`> ...`) เปรียบเทียบกับฐานข้อมูลทางการของ สพฐ. ๒๕๖๖ ครบทุกตัวอักษร: **ตรงกับต้นฉบับ 2,056 / 2,056 ข้อ (100.0%)**
   - เปรียบเทียบเนื้อหาสาระการเรียนรู้แกนกลาง (`**สาระการเรียนรู้แกนกลาง:**`) กับแม่แบบทางการ: **ตรงกับต้นฉบับ 2,056 / 2,056 ข้อ (100.0%)**
   - ผลการประเมิน: **ผ่านเกณฑ์ 2,056 / 2,056 รายการ (100.0%)**

3. **ชั้นที่ 3: สถาปัตยกรรมความสัมพันธ์และการกำกับดูแล (Relational Architecture & Provenance Governance)**
   - จำแนกสถานะการตรวจสอบในระดับ Metadata อย่างชัดเจน:
     - `structural_check_passed: true` (ผ่านเกณฑ์โครงสร้างสมบูรณ์)
     - `source_checked: true` (ผ่านการตรวจสอบเทียบตัวอักษรกับต้นฉบับทางการ)
     - `human_reviewed: false` (อยู่ระหว่างรอการลงนามรับรองรายวิชาโดยคุณครูผู้สอน/ผู้เชี่ยวชาญ)
   - สถาปนาการเชื่อมโยงสองทาง (Bi-directional Linkage): ตัวชี้วัดแกนกลาง 735 รายการเชื่อมโยงไปยังรายวิชาในหลักสูตรสถานศึกษา (`09_หลักสูตรสถานศึกษา`) ผ่านฟิลด์ `relations.assessed_by`
   - ระบบ Single Source of Truth ซิงก์จำนวนฮับดัชนีอย่างเป็นเอกภาพ: **94 ฮับประจำกลุ่มสาระ + 2 มาสเตอร์ฮับ = รวม 96 ไฟล์ดัชนีแกนกลาง** (พร้อม 1 ดัชนีมโนทัศน์สำคัญ และ 11 ฮับสถานศึกษา)
