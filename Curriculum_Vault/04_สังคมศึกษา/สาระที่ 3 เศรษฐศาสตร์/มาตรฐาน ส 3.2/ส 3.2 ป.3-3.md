# ส 3.2 ป.3/3

> อธิบายเหตุผล[[การแข่งขันทางการค้า]]  ที่มีผลทำให้ราคาสินค้าลดลง  11

**วิชา:** สังคมศึกษาฯ
**สาระ:** สาระที่ 3 เศรษฐศาสตร์ (เศรษฐศาสตร์)
**มาตรฐาน:** มาตรฐาน ส 3.2 (เข้าใจระบบและสถาบันทางเศรษฐกิจต่าง ๆ ความสัมพันธ์ทางเศรษฐกิจและความจำเป็น  ของการร่วมมือกันทางเศรษฐกิจในสังคมโลก)

**สาระการเรียนรู้แกนกลาง:**
- ความสำคัญและผลกระทบของ[[การแข่งขันทางการค้า]]ที่มีผลทำให้ราคาสินค้าลดลง
