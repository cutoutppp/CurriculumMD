# ส 3.2 ม.3/1

> อธิบายบทบาทหน้าที่ของรัฐบาลใน[[ระบบเศรษฐกิจ]]

**วิชา:** สังคมศึกษาฯ
**สาระ:** สาระที่ 3 เศรษฐศาสตร์ (เศรษฐศาสตร์)
**มาตรฐาน:** มาตรฐาน ส 3.2 (เข้าใจระบบและสถาบันทางเศรษฐกิจต่าง ๆ ความสัมพันธ์ทางเศรษฐกิจและความจำเป็น  ของการร่วมมือกันทางเศรษฐกิจในสังคมโลก)

**สาระการเรียนรู้แกนกลาง:**
- บทบาทหน้าที่ของรัฐบาลในการพัฒนาประเทศในด้านต่าง ๆ
- บทบาทและกิจกรรมทางเศรษฐกิจของรัฐบาล เช่นการผลิตสินค้าและบริการสาธารณะที่เอกชนไม่ดำเนินการ เช่นไฟฟ้า ถนน โรงเรียน
- บทบาทการเก็บภาษีเพื่อพัฒนาประเทศ  ของรัฐในระดับต่าง ๆ
- บทบาทการแทรกแซงราคาและ               การควบคุมราคาเพื่อการแจกจ่ายและการจัดสรรในทางเศรษฐกิจ
- บทบาทอื่นของรัฐบาลใน[[ระบบเศรษฐกิจ]]ในสังคมไทย
