# ส 3.2 ป.3/1

> บอกสินค้าและบริการที่รัฐจัดหาและให้บริการ แก่ประชาชน

**วิชา:** สังคมศึกษาฯ
**สาระ:** สาระที่ 3 เศรษฐศาสตร์ (เศรษฐศาสตร์)
**มาตรฐาน:** มาตรฐาน ส 3.2 (เข้าใจระบบและสถาบันทางเศรษฐกิจต่าง ๆ ความสัมพันธ์ทางเศรษฐกิจและความจำเป็น  ของการร่วมมือกันทางเศรษฐกิจในสังคมโลก)

**สาระการเรียนรู้แกนกลาง:**
- สินค้าและบริการที่ภาครัฐทุกระดับจัดหาและให้บริการแก่ประชาชน เช่น ถนน โรงเรียน สวนสาธารณะ การสาธารณสุข การบรรเทาสาธารณภัย
