# ส 3.2 ม.2/3

> วิเคราะห์การกระจายของทรัพยากรในโลก  ที่ส่งผลต่อความสัมพันธ์ทางเศรษฐกิจระหว่างประเทศ

**วิชา:** สังคมศึกษาฯ
**สาระ:** สาระที่ 3 เศรษฐศาสตร์ (เศรษฐศาสตร์)
**มาตรฐาน:** มาตรฐาน ส 3.2 (เข้าใจระบบและสถาบันทางเศรษฐกิจต่าง ๆ ความสัมพันธ์ทางเศรษฐกิจและความจำเป็น  ของการร่วมมือกันทางเศรษฐกิจในสังคมโลก)

**สาระการเรียนรู้แกนกลาง:**
- การกระจายของทรัพยากรในโลกที่ส่งผลต่อความสัมพันธ์ทางเศรษฐกิจระหว่างประเทศ เช่น  น้ำมัน  ป่าไม้  ทองคำ  ถ่านหิน  แร่ เป็นต้น
