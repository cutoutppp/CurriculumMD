# ส 3.1 ม.2/4

> อภิปรายแนวทางการคุ้มครองสิทธิของตนเอง  ในฐานะผู้บริโภค

**วิชา:** สังคมศึกษาฯ
**สาระ:** สาระที่ 3 เศรษฐศาสตร์ (เศรษฐศาสตร์)
**มาตรฐาน:** มาตรฐาน ส 3.1 (เข้าใจและสามารถ[[บริหาร]]จัดการทรัพยากรในการผลิตและการบริโภค การใช้ทรัพยากร  ที่มีอยู่จำกัดได้อย่างมีประสิทธิภาพและคุ้มค่า รวมทั้งเข้าใจ[[หลักการของเศรษฐกิจพอเพียง]] เพื่อการดำรงชีวิตอย่างมี[[ดุลยภาพ]])

**สาระการเรียนรู้แกนกลาง:**
- การรักษาและคุ้มครองสิทธิประโยชน์ของ    ผู้บริโภค
- [[กฎหมาย]]คุ้มครองสิทธิผุ้บริโภคและหน่วยงานที่เกี่ยวข้อง
- การดำเนินกิจกรรมพิทักษ์สิทธิและผลประโยชน์ตาม[[กฎหมาย]]ในฐานะผู้บริโภค
- [[แนวทางการปกป้องสิทธิของผู้บริโภค]]
