# ส 3.1 ป.1/1

> ระบุสินค้า และบริการที่ใช้ประโยชน์  ในชีวิตประจำวัน

**วิชา:** สังคมศึกษาฯ
**สาระ:** สาระที่ 3 เศรษฐศาสตร์ (เศรษฐศาสตร์)
**มาตรฐาน:** มาตรฐาน ส 3.1 (เข้าใจและสามารถ[[บริหาร]]จัดการทรัพยากรในการผลิตและการบริโภค การใช้ทรัพยากร  ที่มีอยู่จำกัดได้อย่างมีประสิทธิภาพและคุ้มค่า รวมทั้งเข้าใจ[[หลักการของเศรษฐกิจพอเพียง]] เพื่อการดำรงชีวิตอย่างมี[[ดุลยภาพ]])

**สาระการเรียนรู้แกนกลาง:**
- สินค้าและบริการที่ใช้อยู่ในชีวิตประจำวัน เช่น ดินสอ กระดาษ ยาสีฟัน
- สินค้าและบริการที่ได้มาโดยไม่ใช้เงิน เช่น  มีผู้ให้หรือการใช้ของแลกของ
- [[สินค้าและบริการที่ได้มาจากการใช้เงินซื้อ]]
- [[ใช้ประโยชน์จากสินค้าและบริการให้คุ้มค่า]]
