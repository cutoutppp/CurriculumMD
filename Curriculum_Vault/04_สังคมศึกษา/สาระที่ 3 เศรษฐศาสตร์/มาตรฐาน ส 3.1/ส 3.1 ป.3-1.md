# ส 3.1 ป.3/1

> จำแนกความต้องการและความจำเป็นในการ  ใช้สินค้าและบริการในการดำรงชีวิต

**วิชา:** สังคมศึกษาฯ
**สาระ:** สาระที่ 3 เศรษฐศาสตร์ (เศรษฐศาสตร์)
**มาตรฐาน:** มาตรฐาน ส 3.1 (เข้าใจและสามารถ[[บริหาร]]จัดการทรัพยากรในการผลิตและการบริโภค การใช้ทรัพยากร  ที่มีอยู่จำกัดได้อย่างมีประสิทธิภาพและคุ้มค่า รวมทั้งเข้าใจ[[หลักการของเศรษฐกิจพอเพียง]] เพื่อการดำรงชีวิตอย่างมี[[ดุลยภาพ]])

**สาระการเรียนรู้แกนกลาง:**
- สินค้าที่จำเป็นในการดำรงชีวิตที่ เรียกว่าปัจจัย ๔
- สินค้าที่เป็นความต้องการของมนุษย์อาจ เป็นสินค้าที่จำเป็นหรือไม่จำเป็นต่อการดำรงชีวิต
- ประโยชน์และคุณค่าของสินค้าและบริการ  ที่สนองความต้องการของมนุษย์
- [[หลักการเลือกสินค้าที่จำเป็น]]
- [[ความหมายของผู้ผลิตและผู้บริโภค]]
