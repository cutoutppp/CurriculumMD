# ส 3.1 ม.2/1

> วิเคราะห์ปัจจัยที่มีผลต่อ[[การลงทุน]]และการออม

**วิชา:** สังคมศึกษาฯ
**สาระ:** สาระที่ 3 เศรษฐศาสตร์ (เศรษฐศาสตร์)
**มาตรฐาน:** มาตรฐาน ส 3.1 (เข้าใจและสามารถ[[บริหาร]]จัดการทรัพยากรในการผลิตและการบริโภค การใช้ทรัพยากร  ที่มีอยู่จำกัดได้อย่างมีประสิทธิภาพและคุ้มค่า รวมทั้งเข้าใจ[[หลักการของเศรษฐกิจพอเพียง]] เพื่อการดำรงชีวิตอย่างมี[[ดุลยภาพ]])

**สาระการเรียนรู้แกนกลาง:**
- ความหมายและความสำคัญของ[[การลงทุน]]และการออมต่อ[[ระบบเศรษฐกิจ]]
- การ[[บริหาร]]จัด[[การเงิน]]ออมและ[[การลงทุน]] ภาคครัวเรือน
- ปัจจัยของ[[การลงทุน]]และการออมคือ อัตราดอกเบี้ย รวมทั้งปัจจัยอื่น ๆ เช่น ค่าของเงิน เทคโนโลยี การคาดเดาเกี่ยวกับอนาคต
- [[ปัญหาของการลงทุนและการออมในสังคมไทย]]
