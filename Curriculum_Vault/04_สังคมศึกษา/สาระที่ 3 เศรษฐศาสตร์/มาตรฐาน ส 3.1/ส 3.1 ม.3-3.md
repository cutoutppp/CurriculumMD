# ส 3.1 ม.3/3

> วิเคราะห์ความสัมพันธ์ระหว่างแนวคิด [[เศรษฐกิจพอเพียง]]กับระบบ[[สหกรณ์]]

**วิชา:** สังคมศึกษาฯ
**สาระ:** สาระที่ 3 เศรษฐศาสตร์ (เศรษฐศาสตร์)
**มาตรฐาน:** มาตรฐาน ส 3.1 (เข้าใจและสามารถ[[บริหาร]]จัดการทรัพยากรในการผลิตและการบริโภค การใช้ทรัพยากร  ที่มีอยู่จำกัดได้อย่างมีประสิทธิภาพและคุ้มค่า รวมทั้งเข้าใจ[[หลักการของเศรษฐกิจพอเพียง]] เพื่อการดำรงชีวิตอย่างมี[[ดุลยภาพ]])

**สาระการเรียนรู้แกนกลาง:**
- แนวคิดของ[[เศรษฐกิจพอเพียง]]กับการพัฒนาในระดับต่าง ๆ
- [[หลักการสำคัญของระบบสหกรณ์]]
- ความสัมพันธ์ระหว่างแนวคิดเศรษฐกิพอเพียงกับหลักการและระบบของ[[สหกรณ์]]เพื่อประยุกต์ใช้ใน[[การพัฒนาเศรษฐกิจ]]ชุมชน
