# ส 3.1 ม.3/1

> อธิบายกลไกราคาใน[[ระบบเศรษฐกิจ]]

**วิชา:** สังคมศึกษาฯ
**สาระ:** สาระที่ 3 เศรษฐศาสตร์ (เศรษฐศาสตร์)
**มาตรฐาน:** มาตรฐาน ส 3.1 (เข้าใจและสามารถ[[บริหาร]]จัดการทรัพยากรในการผลิตและการบริโภค การใช้ทรัพยากร  ที่มีอยู่จำกัดได้อย่างมีประสิทธิภาพและคุ้มค่า รวมทั้งเข้าใจ[[หลักการของเศรษฐกิจพอเพียง]] เพื่อการดำรงชีวิตอย่างมี[[ดุลยภาพ]])

**สาระการเรียนรู้แกนกลาง:**
- [[ความหมายและประเภทของตลาด]]
- [[ความหมายและตัวอย่างของอุปสงค์และอุปทาน]]
- ความหมายและความสำคัญของกลไกราคาและการกำหนดราคาใน[[ระบบเศรษฐกิจ]]
- หลักการปรับและเปลี่ยนแปลงราคาสินค้าและบริการ
