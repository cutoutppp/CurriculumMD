# ส 3.1 ม.3/2

> มีส่วนร่วมในการ แก้ไขปัญหาและพัฒนาท้องถิ่น  ตามปรัชญาของ[[เศรษฐกิจพอเพียง]]

**วิชา:** สังคมศึกษาฯ
**สาระ:** สาระที่ 3 เศรษฐศาสตร์ (เศรษฐศาสตร์)
**มาตรฐาน:** มาตรฐาน ส 3.1 (เข้าใจและสามารถ[[บริหาร]]จัดการทรัพยากรในการผลิตและการบริโภค การใช้ทรัพยากร  ที่มีอยู่จำกัดได้อย่างมีประสิทธิภาพและคุ้มค่า รวมทั้งเข้าใจ[[หลักการของเศรษฐกิจพอเพียง]] เพื่อการดำรงชีวิตอย่างมี[[ดุลยภาพ]])

**สาระการเรียนรู้แกนกลาง:**
- สำรวจสภาพปัจจุบันปัญหาท้องถิ่นทั้งทางด้านสังคม เศรษฐกิจและสิ่งแวดล้อม
- วิเคราะห์ปัญหาของท้องถิ่นโดยใช้ปรัชญาของ[[เศรษฐกิจพอเพียง]]
- แนวทางการแก้ไขและพัฒนาท้องถิ่นตามปรัชญาของ[[เศรษฐกิจพอเพียง]]
