# ส 3.1 ม.4-6/3

**วิชา:** สังคมศึกษา
**สาระ:** สาระที่ 3 เศรษฐศาสตร์
**มาตรฐาน:** มาตรฐาน ส 3.1

**สาระการเรียนรู้แกนกลาง:**
