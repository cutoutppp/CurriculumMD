# ส 3.1 ป.1/3

> ยกตัวอย่างการ ใช้ทรัพยากรในชีวิตประจำวัน อย่างประหยัด

**วิชา:** สังคมศึกษาฯ
**สาระ:** สาระที่ 3 เศรษฐศาสตร์ (เศรษฐศาสตร์)
**มาตรฐาน:** มาตรฐาน ส 3.1 (เข้าใจและสามารถ[[บริหาร]]จัดการทรัพยากรในการผลิตและการบริโภค การใช้ทรัพยากร  ที่มีอยู่จำกัดได้อย่างมีประสิทธิภาพและคุ้มค่า รวมทั้งเข้าใจ[[หลักการของเศรษฐกิจพอเพียง]] เพื่อการดำรงชีวิตอย่างมี[[ดุลยภาพ]])

**สาระการเรียนรู้แกนกลาง:**
- ทรัพยากรที่ใช้ในชีวิตประจำวัน เช่น ดินสอ กระดาษ  เสื้อผ้า อาหาร
-    ทรัพยากรส่วนรวม เช่น โต๊ะ เก้าอี้ นักเรียน  
- [[สาธารณูปโภคต่าง ๆ]]
-    [[วิธีการใช้ทรัพยากรทั้งของส่วนตัวและ]]
-       [[ส่วนรวมอย่างถูกต้อง และประหยัดและคุ้มค่า]]
