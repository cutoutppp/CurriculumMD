# ส 3.1 ป.2/1

> ระบุทรัพยากรที่นำมาผลิตสินค้าและบริการ  ที่ใช้ในชีวิตประจำวัน

**วิชา:** สังคมศึกษาฯ
**สาระ:** สาระที่ 3 เศรษฐศาสตร์ (เศรษฐศาสตร์)
**มาตรฐาน:** มาตรฐาน ส 3.1 (เข้าใจและสามารถ[[บริหาร]]จัดการทรัพยากรในการผลิตและการบริโภค การใช้ทรัพยากร  ที่มีอยู่จำกัดได้อย่างมีประสิทธิภาพและคุ้มค่า รวมทั้งเข้าใจ[[หลักการของเศรษฐกิจพอเพียง]] เพื่อการดำรงชีวิตอย่างมี[[ดุลยภาพ]])

**สาระการเรียนรู้แกนกลาง:**
- ทรัพยากรที่นำมาใช้ในการผลิตสินค้าและบริการที่ใช้ในครอบครัวและโรงเรียน เช่น ดินสอและกระดาษที่ผลิตจากไม้ รวมทั้งเครื่องจักรและแรงงานการผลิต
- ผลของการใช้ทรัพยากรในการผลิตที่หลากหลายที่มีต่อราคา คุณค่าและประโยชน์ของสินค้าและบริการ รวมทั้งสิ่งแวดล้อม
