# ส 3.1 ม.1/2

> วิเคราะห์ค่านิยม และพฤติกรรมการบริโภคของ  คนในสังคมซึ่งส่งผลต่อเศรษฐกิจ ของชุมชนและประเทศ

**วิชา:** สังคมศึกษาฯ
**สาระ:** สาระที่ 3 เศรษฐศาสตร์ (เศรษฐศาสตร์)
**มาตรฐาน:** มาตรฐาน ส 3.1 (เข้าใจและสามารถ[[บริหาร]]จัดการทรัพยากรในการผลิตและการบริโภค การใช้ทรัพยากร  ที่มีอยู่จำกัดได้อย่างมีประสิทธิภาพและคุ้มค่า รวมทั้งเข้าใจ[[หลักการของเศรษฐกิจพอเพียง]] เพื่อการดำรงชีวิตอย่างมี[[ดุลยภาพ]])

**สาระการเรียนรู้แกนกลาง:**
- ความหมายและความสำคัญของการบริโภคอย่างมีประสิทธิภาพ
- [[หลักการในการบริโภคที่ดี]]
- [[ปัจจัยที่มีอิทธิพลต่อพฤติกรรมการบริโภค]]
- ค่านิยมและพฤติกรรมของการบริโภคของคนในสังคมปัจจุบัน รวมทั้งผลดีและผลเสียของพฤติกรรมดังกล่าว
