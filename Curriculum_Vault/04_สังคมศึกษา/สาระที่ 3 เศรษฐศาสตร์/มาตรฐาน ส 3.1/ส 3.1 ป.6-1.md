# ส 3.1 ป.6/1

> อธิบายบทบาทของผู้ผลิตที่มี[[ความรับผิดชอบ]]

**วิชา:** สังคมศึกษาฯ
**สาระ:** สาระที่ 3 เศรษฐศาสตร์ (เศรษฐศาสตร์)
**มาตรฐาน:** มาตรฐาน ส 3.1 (เข้าใจและสามารถ[[บริหาร]]จัดการทรัพยากรในการผลิตและการบริโภค การใช้ทรัพยากร  ที่มีอยู่จำกัดได้อย่างมีประสิทธิภาพและคุ้มค่า รวมทั้งเข้าใจ[[หลักการของเศรษฐกิจพอเพียง]] เพื่อการดำรงชีวิตอย่างมี[[ดุลยภาพ]])

**สาระการเรียนรู้แกนกลาง:**
- บทบาทของผู้ผลิตที่มีคุณภาพ   เช่น                คำนึงถึงสิ่งแวดล้อม มีจรรยาบรรณ           [[ความรับผิดชอบ]]ต่อสังคม วางแผนก่อนเริ่มลงมือทำกิจกรรมต่าง ๆ เพื่อลดความผิดพลาดและการสูญเสีย ฯลฯ
- ทัศนคติในการใช้ทรัพยากรอย่างมีประสิทธิภาพและประสิทธิผล
- [[ประโยชน์ของการผลิตสินค้าที่มีคุณภาพ]]
