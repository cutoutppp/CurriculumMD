# ส 3.1 ม.1/3

> อธิบายความเป็นมา  หลักการและความสำคัญของ ปรัชญาของ[[เศรษฐกิจพอเพียง]]  ต่อสังคมไทย

**วิชา:** สังคมศึกษาฯ
**สาระ:** สาระที่ 3 เศรษฐศาสตร์ (เศรษฐศาสตร์)
**มาตรฐาน:** มาตรฐาน ส 3.1 (เข้าใจและสามารถ[[บริหาร]]จัดการทรัพยากรในการผลิตและการบริโภค การใช้ทรัพยากร  ที่มีอยู่จำกัดได้อย่างมีประสิทธิภาพและคุ้มค่า รวมทั้งเข้าใจ[[หลักการของเศรษฐกิจพอเพียง]] เพื่อการดำรงชีวิตอย่างมี[[ดุลยภาพ]])

**สาระการเรียนรู้แกนกลาง:**
- ความหมายและความเป็นมาของปรัชญาของ[[เศรษฐกิจพอเพียง]]
- ความเป็นมาของ[[เศรษฐกิจพอเพียง]] และหลักการทรงงานของพระบาทสมเด็จ           พระเจ้าอยู่หัวรวมทั้งโครงการตามพระราชดำริ
- [[หลักการของเศรษฐกิจพอเพียง]]
- การประยุกต์ใช้ปรัชญาของ[[เศรษฐกิจพอเพียง]] ในการดำรงชีวิต
- ความสำคัญ คุณค่าและประโยชน์ของปรัชญาของ[[เศรษฐกิจพอเพียง]]ต่อสังคมไทย
