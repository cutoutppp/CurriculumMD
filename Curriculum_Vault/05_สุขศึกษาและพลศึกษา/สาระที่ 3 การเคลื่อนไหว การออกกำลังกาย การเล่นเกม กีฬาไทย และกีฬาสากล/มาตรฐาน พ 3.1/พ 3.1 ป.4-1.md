# พ 3.1 ป.4/1

> ควบคุมตนเองเมื่อใช้ทักษะ การเคลื่อนไหวในลักษณะผสมผสานได้ทั้งแบบ อยู่กับที่ เคลื่อนที่ และใช้อุปกรณ์ประกอบ

**วิชา:** สุขศึกษาและพลศึกษา
**สาระ:** [[00_สาระที่ 3 การเคลื่อนไหว [[การออกกำลังกาย]] การเล่นเกม กีฬาไทย และกีฬาสากล|สาระที่ 3 การเคลื่อนไหว การออกกำลังกาย การเล่นเกม กีฬาไทย และกีฬาสากล]]
**มาตรฐาน:** [[00_มาตรฐาน พ 3.1|มาตรฐาน พ 3.1]] (เข้าใจ มีทักษะในการเคลื่อนไหว กิจกรรมทางกาย การเล่นเกม และกีฬา)

**สาระการเรียนรู้แกนกลาง:**
- การจัดรูปแบบการเคลื่อนไหวร่างกาย แบบผสมผสานและการปฏิบัติ กิจกรรมทางกายทั้งแบบอยู่กับที่ เคลื่อนที่ และใช้อุปกรณ์ประกอบ ตามแบบที่กำหนด เช่น การฝึก กายบริหาร ยืดหยุ่นขั้นพื้นฐาน เป็นต้น
