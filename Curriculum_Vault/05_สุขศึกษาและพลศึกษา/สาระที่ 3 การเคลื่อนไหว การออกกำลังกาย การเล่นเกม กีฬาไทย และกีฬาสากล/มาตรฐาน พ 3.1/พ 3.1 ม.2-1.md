# พ 3.1 ม.2/1

> นำผลการปฏบิ ัติตนเกี่ยวกับทักษะ กลไกและทักษะการเคลื่อนไหวในการเล่นกีฬา จากแหล่งข้อมูลที่หลากหลายมาสรุปเป็นวิธีที่ เหมาะสมในบริบทของตนเอง

**วิชา:** สุขศึกษาและพลศึกษา
**สาระ:** [[00_สาระที่ 3 การเคลื่อนไหว [[การออกกำลังกาย]] การเล่นเกม กีฬาไทย และกีฬาสากล|สาระที่ 3 การเคลื่อนไหว การออกกำลังกาย การเล่นเกม กีฬาไทย และกีฬาสากล]]
**มาตรฐาน:** [[00_มาตรฐาน พ 3.1|มาตรฐาน พ 3.1]] (เข้าใจ มีทักษะในการเคลื่อนไหว กิจกรรมทางกาย การเล่นเกม และกีฬา)

**สาระการเรียนรู้แกนกลาง:**
- เทคนิคและวิธีการเล่นกีฬาไทยและ กีฬาสากลที่เลือก เช่น กรีฤาประเภทลู่ และลาน วอลเลย์บอล บาสเกตบอล ดาบสองมือ เทนนิส ตะกร้อข้ามตาข่าย ฟุตบอล การนำหลักการ ความรู้ และทักษะ
