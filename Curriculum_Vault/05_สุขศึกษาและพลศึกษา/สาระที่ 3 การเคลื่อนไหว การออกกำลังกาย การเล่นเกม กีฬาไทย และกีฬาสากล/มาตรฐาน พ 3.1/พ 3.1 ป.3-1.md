# พ 3.1 ป.3/1

> ควบคุมการเคลื่อนไหวร่างกาย ขณะอยู่กับที่ เคลื่อนที่ และใช้อุปกรณ์ประกอบ อย่างมีทิศทาง

**วิชา:** สุขศึกษาและพลศึกษา
**สาระ:** [[00_สาระที่ 3 การเคลื่อนไหว การออกกำลังกาย การเล่นเกม กีฬาไทย และกีฬาสากล|สาระที่ 3 การเคลื่อนไหว การออกกำลังกาย การเล่นเกม กีฬาไทย และกีฬาสากล]]
**มาตรฐาน:** [[00_มาตรฐาน พ 3.1|มาตรฐาน พ 3.1]] (เข้าใจ มีทักษะในการเคลื่อนไหว กิจกรรมทางกาย การเล่นเกม และกีฬา)

**สาระการเรียนรู้แกนกลาง:**
- การเคลื่อนไหวร่างกายแบบอยู่กับที่ เช่น ย่อยืด เขย่ง พับตัว เคลื่อนไหว
- ลำตัว การเคลื่อนไหวแบบเคลื่อนที่ เช่น เดินต่อเท้า เดินถอยหลัง กระโจน และแบบใช้อุปกรณ์ประกอบโดยมี การบังคับทิศทาง เช่น ดีด ขว้าง โยน และรับ วิธีการควบคุมการเคลื่อนไหวร่างกาย แบบต่าง ๆ อย่างมีทิศทาง
