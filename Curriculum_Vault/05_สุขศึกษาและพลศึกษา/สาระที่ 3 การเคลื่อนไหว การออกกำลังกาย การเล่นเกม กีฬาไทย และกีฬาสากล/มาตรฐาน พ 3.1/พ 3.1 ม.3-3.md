# พ 3.1 ม.3/3

> ร่วมกิจกรรมนันทนาการ อย่างน้อย ๑ กิจกรรมและนำหลักความรู้ วิธีการไปขยายผลการเรียนรู้ให้กับผู้อื่น

**วิชา:** สุขศึกษาและพลศึกษา
**สาระ:** [[00_สาระที่ 3 การเคลื่อนไหว [[การออกกำลังกาย]] การเล่นเกม กีฬาไทย และกีฬาสากล|สาระที่ 3 การเคลื่อนไหว การออกกำลังกาย การเล่นเกม กีฬาไทย และกีฬาสากล]]
**มาตรฐาน:** [[00_มาตรฐาน พ 3.1|มาตรฐาน พ 3.1]] (เข้าใจ มีทักษะในการเคลื่อนไหว กิจกรรมทางกาย การเล่นเกม และกีฬา)

**สาระการเรียนรู้แกนกลาง:**
- โดยคำนึงถึง ผลที่เกิดต่อผู้อื่นและสังคม กีฬาประเภทบุคคล/คู่ ประเภททีม เช่น ฟุตซอล รักบี้ ฟุตบอล ยิมนาสติก ลีลาศ ซอฟท์บอล เทนนิส เซปักตะกร้อ มวยไทย กระบี่กระบอง พลอง ง้าว การเคลื่อนไหวที่สร้างสรรค์ เช่น
