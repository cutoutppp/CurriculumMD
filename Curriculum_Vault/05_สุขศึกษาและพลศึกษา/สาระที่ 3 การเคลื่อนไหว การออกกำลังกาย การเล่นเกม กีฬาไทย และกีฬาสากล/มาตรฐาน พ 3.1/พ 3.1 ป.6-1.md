# พ 3.1 ป.6/1

> แสดงทักษะการเคลื่อนไหวร่วมกับ ผู้อื่นในลักษณะแบบผลัด และแบบผสมผสานได้ ตามลำดับทั้งแบบอยู่กับที่ เคลื่อนที่ และใช้อุปกรณ์ ประกอบและการเคลื่อนไหวประกอบเพลง

**วิชา:** สุขศึกษาและพลศึกษา
**สาระ:** [[00_สาระที่ 3 การเคลื่อนไหว [[การออกกำลังกาย]] การเล่นเกม กีฬาไทย และกีฬาสากล|สาระที่ 3 การเคลื่อนไหว การออกกำลังกาย การเล่นเกม กีฬาไทย และกีฬาสากล]]
**มาตรฐาน:** [[00_มาตรฐาน พ 3.1|มาตรฐาน พ 3.1]] (เข้าใจ มีทักษะในการเคลื่อนไหว กิจกรรมทางกาย การเล่นเกม และกีฬา)

**สาระการเรียนรู้แกนกลาง:**
- หลักการเพิ่มพูนความสามารถในการ เคลื่อนไหวที่ใช้ทักษะกลไกและทักษะ พื้นฐานที่นำไปสู่การพัฒนาทักษะ
