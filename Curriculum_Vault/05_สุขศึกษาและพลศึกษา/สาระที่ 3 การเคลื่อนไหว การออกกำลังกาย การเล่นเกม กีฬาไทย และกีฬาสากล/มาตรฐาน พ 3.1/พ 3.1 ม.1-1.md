# พ 3.1 ม.1/1

> เพิ่มพูนความสามารถของตน ตามหลักการเคลื่อนไหวที่ใช้ทักษะกลไกและทักษะ พื้นฐานที่นำไปสู่การพัฒนาทักษะการเล่นกีฬา

**วิชา:** สุขศึกษาและพลศึกษา
**สาระ:** [[00_สาระที่ 3 การเคลื่อนไหว การออกกำลังกาย การเล่นเกม กีฬาไทย และกีฬาสากล|สาระที่ 3 การเคลื่อนไหว การออกกำลังกาย การเล่นเกม กีฬาไทย และกีฬาสากล]]
**มาตรฐาน:** [[00_มาตรฐาน พ 3.1|มาตรฐาน พ 3.1]] (เข้าใจ มีทักษะในการเคลื่อนไหว กิจกรรมทางกาย การเล่นเกม และกีฬา)

**สาระการเรียนรู้แกนกลาง:**
- นันทนาการไปใช้เชื่อมโยงสัมพันธ์กับ วิชาอื่น การนำผลการปฏิบัติตนเกี่ยวกับทักษะ กลไกและทักษะการเคลื่อนไหวในการ เล่นกีฬาจากแหล่งข้อมูลที่หลากหลาย มาสรุปเป็นวิธีที่เหมาะสมในบริบทของ ตนเองในการเล่นกีฬา
