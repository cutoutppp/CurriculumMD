# พ 3.2 ป.1/1

> ออกกำลังกาย และเล่นเกม ตามคำแนะนำ อย่างสนุกสนาน

**วิชา:** สุขศึกษาและพลศึกษา
**สาระ:** [[00_สาระที่ 3 การเคลื่อนไหว [[การออกกำลังกาย]] การเล่นเกม กีฬาไทย และกีฬาสากล|สาระที่ 3 การเคลื่อนไหว การออกกำลังกาย การเล่นเกม กีฬาไทย และกีฬาสากล]]
**มาตรฐาน:** [[00_มาตรฐาน พ 3.2|มาตรฐาน พ 3.2]] (รักการออกกำลังกาย การเล่นเกม และการเล่นกีฬา ปฏิบัติเป็นประจำอย่างสม่ำเสมอ มีวินัย เคารพสิทธิ กฎ กติกา มีน้ำใจนักกีฬา มีจิตวิญญาณในการแข่งขัน และชื่นชมในสุนทรียภาพของการกีฬา)

**สาระการเรียนรู้แกนกลาง:**
- การออกกำลังกายและการเล่นเกม เบ็ดเตล็ด
