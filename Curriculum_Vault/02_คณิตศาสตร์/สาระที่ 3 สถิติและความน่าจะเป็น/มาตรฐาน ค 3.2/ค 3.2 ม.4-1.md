# ค 3.2 ม.4/1

> เข้าใจและใช้หลักการบวกและการคูณ การเรียงสับเปลี่ยนและการจัดหมู่ในการแก้ปัญหา

**วิชา:** คณิตศาสตร์
**สาระ:** [[00_สาระที่ 3 [[สถิติ]]และความน่าจะเป็น|สาระที่ 3 สถิติและความน่าจะเป็น]]
**มาตรฐาน:** [[00_มาตรฐาน ค 3.2|มาตรฐาน ค 3.2]] (เข้าใจหลักการนับเบื้องต้น [[ความน่าจะเป็น]] และนำไปใช้)

**สาระการเรียนรู้แกนกลาง:**
- หลักการนับและความน่าจะเป็น: กฎเกณฑ์เบื้องต้นเกี่ยวกับการนับ, การเรียงสับเปลี่ยนและการจัดหมู่, ความน่าจะเป็นของเหตุการณ์
