# ค 3.2 ม.3/1

> เข้าใจเกี่ยวกับ การทดลองสุ่มและนำผลที่ได้ ไปหา[[ความน่าจะเป็น]]ของเหตุการณ์

**วิชา:** คณิตศาสตร์
**สาระ:** [[00_สาระที่ 3 [[สถิติ]]และความน่าจะเป็น|สาระที่ 3 สถิติและความน่าจะเป็น]]
**มาตรฐาน:** [[00_มาตรฐาน ค 3.2|มาตรฐาน ค 3.2]] (เข้าใจหลักการนับเบื้องต้น ความน่าจะเป็น และนำไปใช้)

**สาระการเรียนรู้แกนกลาง:**
- ความน่าจะเป็น: โอกาสของเหตุการณ์, การทดลองสุ่มและเหตุการณ์, ความน่าจะเป็นของเหตุการณ์และการนำไปใช้
