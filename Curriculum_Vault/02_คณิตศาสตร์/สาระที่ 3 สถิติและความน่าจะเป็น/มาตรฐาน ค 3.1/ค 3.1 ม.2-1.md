# ค 3.1 ม.2/1

> เข้าใจและใช้ความรู้ ทาง[[สถิติ]]ในการนำเสนอข้อมูลและ วิเคราะห์ข้อมูลจากแผนภาพจุด แผนภาพต้น-ใบ ฮิสโทแกรม และค่ากลางของข้อมูล และแปล ความหมายผลลัพธ์ รวมทั้งนำสถิติ ไปใช้ในชีวิตจริงโดยใช้เทคโนโลยี ทเี่ หมาะสม

**วิชา:** คณิตศาสตร์
**สาระ:** [[00_สาระที่ 3 สถิติและความน่าจะเป็น|สาระที่ 3 สถิติและความน่าจะเป็น]]
**มาตรฐาน:** [[00_มาตรฐาน ค 3.1|มาตรฐาน ค 3.1]] (เข้าใจกระบวนการทางสถิติ และใช้ความรู้ทางสถิติในการแก้ปัญหา)

**สาระการเรียนรู้แกนกลาง:**
- สถิติ: แผนภาพจุด แผนภาพต้น-ใบ ฮิสโทแกรม, ค่าเฉลี่ยเลขคณิต มัธยฐาน ฐานนิยม, การแปลความหมายและการนำไปใช้
