# ค 3.1 ม.6/1

> เข้าใจและใช้ความรู้ ทาง[[สถิติ]]ในการนำเสนอข้อมูลและ แปลความหมายของค่าสถิติ เพื่อประกอบการตัดสินใจ

**วิชา:** คณิตศาสตร์
**สาระ:** [[00_สาระที่ 3 สถิติและความน่าจะเป็น|สาระที่ 3 สถิติและความน่าจะเป็น]]
**มาตรฐาน:** [[00_มาตรฐาน ค 3.1|มาตรฐาน ค 3.1]] (เข้าใจกระบวนการทางสถิติ และใช้ความรู้ทางสถิติในการแก้ปัญหา)

**สาระการเรียนรู้แกนกลาง:**
- สถิติ: ข้อมูลเชิงคุณภาพและเชิงปริมาณ, การวัดตำแหน่งที่ของข้อมูล (เปอร์เซ็นไทล์), การวัดค่ากลางและการวัดการกระจาย, การแจกแจงปกติ
