# ค 3.1 ม.3/1

> เข้าใจและใช้ความรู้ ทาง[[สถิติ]]ในการนำเสนอและ วิเคราะห์ข้อมูล จากแผนภาพกล่อง และแปลความหมายผลลัพธ์ รวมทั้งนำสถิติไปใช้ในชีวิตจริง โดยใช้เทคโนโลยีที่เหมาะสม

**วิชา:** คณิตศาสตร์
**สาระ:** [[00_สาระที่ 3 สถิติและความน่าจะเป็น|สาระที่ 3 สถิติและความน่าจะเป็น]]
**มาตรฐาน:** [[00_มาตรฐาน ค 3.1|มาตรฐาน ค 3.1]] (เข้าใจกระบวนการทางสถิติ และใช้ความรู้ทางสถิติในการแก้ปัญหา)

**สาระการเรียนรู้แกนกลาง:**
- สถิติ: แผนภาพกล่อง, การกระจายของข้อมูล พิสัยและส่วนเบี่ยงเบนควอร์ไทล์, การแปลความหมาย
