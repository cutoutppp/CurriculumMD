# ค 3.1 ป.3/1

> เขียนแผนภูมิ รูปภาพ และใช้ข้อมูลจากแผนภูมิ รูปภาพในการหาคำตอบของโจทย์ ปัญหา

**วิชา:** คณิตศาสตร์
**สาระ:** [[00_สาระที่ 3 [[สถิติ]]และความน่าจะเป็น|สาระที่ 3 สถิติและความน่าจะเป็น]]
**มาตรฐาน:** [[00_มาตรฐาน ค 3.1|มาตรฐาน ค 3.1]] (เข้าใจกระบวนการทางสถิติ และใช้ความรู้ทางสถิติในการแก้ปัญหา)

**สาระการเรียนรู้แกนกลาง:**
- การนำเสนอข้อมูล: การเก็บรวบรวมข้อมูล, แผนภูมิรูปภาพและตารางทางเดียว
