# ท 3.1 ป.2/5

> พูดแสดงความคิดเห็นและความรู้สึกจากเรื่อง ที่ฟังและดู

**วิชา:** ภาษาไทย
**สาระ:** [[00_สาระที่ 3 การฟัง การดู และการพูด|สาระที่ 3 การฟัง การดู และการพูด]]
**มาตรฐาน:** [[00_มาตรฐาน ท 3.1|มาตรฐาน ท 3.1]] (สามารถเลือกฟังและดูอย่างมีวิจารณญาณ และพูดแสดงความรู้ ความคิด และความรู้สึกในโอกาสต่าง ๆ อย่างมีวิจารณญาณและสร้างสรรค์)

**สาระการเรียนรู้แกนกลาง:**
- การฟังและปฏิบัติตามคำแนะนำ
- การฟังและปฏิบัติตามคำแนะนำ คำสั่งง่ายๆ
- คำสั่งง่ายๆ การจับใจความและพูดแสดงความ คิดเห็น ความรู้สึกจากเรื่องที่ฟังและดู ทั้งที่เป็นความรู้และความบันเทิง เช่น - เรื่องเล่าและสารคดีสำหรับเด็ก
