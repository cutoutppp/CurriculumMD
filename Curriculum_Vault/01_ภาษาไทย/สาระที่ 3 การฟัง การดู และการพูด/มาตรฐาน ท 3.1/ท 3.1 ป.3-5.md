# ท 3.1 ป.3/5

> พูดสื่อสารได้ชัดเจน ตรงตามวัตถุประสงค์

**วิชา:** ภาษาไทย
**สาระ:** [[00_สาระที่ 3 การฟัง การดู และการพูด|สาระที่ 3 การฟัง การดู และการพูด]]
**มาตรฐาน:** [[00_มาตรฐาน ท 3.1|มาตรฐาน ท 3.1]] (สามารถเลือกฟังและดูอย่างมีวิจารณญาณ และพูดแสดงความรู้ ความคิด และความรู้สึกในโอกาสต่าง ๆ อย่างมีวิจารณญาณและสร้างสรรค์)

**สาระการเรียนรู้แกนกลาง:**
- การพูดสื่อสารในชีวิตประจำวัน เช่น
- การแนะนำตนเอง
- การแนะนำสถานที่ในโรงเรียน และในชุมชน
- การแนะนำ เชิญชวนเกี่ยวกับ การปฏิบัติตนในด้านต่างๆ เช่น การรักษาความสะอาดของร่างกาย
- การเล่าประสบการณ์ในชีวิตประจำวัน
- การพูดในโอกาสต่างๆ เช่น การพูด ขอร้อง การพูดทักทาย การกล่าว ขอบคุณและขอโทษ การพูดปฬิเสธ และการพูดซักถาม
