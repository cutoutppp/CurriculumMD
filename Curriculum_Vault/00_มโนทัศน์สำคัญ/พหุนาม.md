### 🎯 ตัวชี้วัดที่เชื่อมโยง (8 ตัวชี้วัด)
- [[ค 1.1 ม.2-1|ค 1.1 ม.2/1]]: เข้าใจและใช้สมบัติของเลขยกกำลังที่มี เลขชี้กำลังเป็นจำนวนเต็มในการแก้ปัญหาคณิตศา...
- [[ค 1.1 ม.2-2|ค 1.1 ม.2/2]]: เข้าใจจำนวนจริง และความสัมพันธ์ของจำนวนจริง และใช้สมบัติของจำนวนจริงในการ แก้ปัญ...
- [[ค 1.1 ม.4-1|ค 1.1 ม.4/1]]: เข้าใจและใช้ความรู้ เกี่ยวกับเซตและตรรกศาสตร์ เบื้องต้นในการสื่อสารและ สื่อความห...
- [[ค 1.1 ม.5-1|ค 1.1 ม.5/1]]: เข้าใจความหมาย และใช้สมบัติเกี่ยวกับการบวก การคูณ การเท่ากัน และการไม่เท่ากัน ขอ...
- [[ค 1.2 ม.2-1|ค 1.2 ม.2/1]]: เข้าใจหลักการการดำเนินการของพหุนาม และ ใช้พหุนามในการแก้ปัญหาคณิตศาสตร์...
- [[ค 1.2 ม.2-2|ค 1.2 ม.2/2]]: เข้าใจและใช้การ แยกตัวประกอบของพหุนามดีกรีสอง ในการแก้ปัญหาทางคณิตศาสตร์...
- [[ค 1.2 ม.3-1|ค 1.2 ม.3/1]]: เข้าใจและใช้การ แยกตัวประกอบของพหุนามที่มี ดีกรีสูงกว่าสองในการแก้ปัญหา คณิตศาสต...
- [[ค 1.3 ม.5-1|ค 1.3 ม.5/1]]: เข้าใจและใช้ความรู้เกี่ยวกับดอกเบี้ยและมูลค่า ของเงินในการแก้ปัญหา...
