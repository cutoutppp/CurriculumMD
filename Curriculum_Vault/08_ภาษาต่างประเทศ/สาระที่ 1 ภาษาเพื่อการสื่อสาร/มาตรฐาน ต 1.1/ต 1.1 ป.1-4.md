# ต 1.1 ป.1/4

> ตอบคำถามจากการ ฟังเรื่องใกล้ตัว

**วิชา:** ภาษาต่างประเทศ
**สาระ:** [[00_สาระที่ 1 ภาษาเพื่อการสื่อสาร|สาระที่ 1 ภาษาเพื่อการสื่อสาร]]
**มาตรฐาน:** [[00_มาตรฐาน ต 1.1|มาตรฐาน ต 1.1]] (เข้าใจและตีความเรื่องที่ฟังและอ่านจากสื่อประเภทต่าง ๆ และแสดงความคิดเห็นอย่างมีเหตุผล)

**สาระการเรียนรู้แกนกลาง:**
- บทอ่านเกี่ยวกับเรื่องใกล้ตัวหรือนิทาน ที่มีภาพประกอบ ประโยคคำถามและคำตอบ
- Yes/No Question เช่น Is it a/an..? Yes, it is./ No, it is not. etc.
- Question เช่น What is it? It is a/an... etc.
