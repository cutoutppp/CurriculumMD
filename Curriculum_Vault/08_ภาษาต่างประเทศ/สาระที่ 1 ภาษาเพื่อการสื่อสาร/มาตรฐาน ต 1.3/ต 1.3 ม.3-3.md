# ต 1.3 ม.3/3

> พูดและเขียนแสดงความคิดเห็นเกี่ยวกับ กิจกรรม ประสบการณ์ และเหตุการณ์ ทั้งในท้องถิ่น สังคม และโลก พร้อมทั้งให้เหตุผลและยกตัวอย่างประกอบ

**วิชา:** ภาษาต่างประเทศ
**สาระ:** [[00_สาระที่ 1 ภาษาเพื่อการสื่อสาร|สาระที่ 1 ภาษาเพื่อการสื่อสาร]]
**มาตรฐาน:** [[00_มาตรฐาน ต 1.3|มาตรฐาน ต 1.3]] (นำเสนอข้อมูลข่าวสาร ความคิดรวบยอด และความคิดเห็นในเรื่องต่าง ๆ โดยการพูดและการเขียน)

**สาระการเรียนรู้แกนกลาง:**
- การแสดงความคิดเห็นและการให้เหตุผล ประกอบเกี่ยวกับกิจกรรม ประสบการณ์ และเหตุการณ์
