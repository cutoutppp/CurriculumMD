# ต 3.1 ม.3/1

> ค้นคว้า รวบรวม และสรุปข้อมูล/ข้อเท็จจริง ที่เกี่ยวข้องกับกลุ่มสาระการเรียนรู้อื่นจากแหล่งเรียนรู้ และนำเสนอด้วยการพูดและการเขียน

**วิชา:** ภาษาต่างประเทศ
**สาระ:** [[00_สาระที่ 3 ภาษากับความสัมพันธ์กับกลุ่มสาระการเรียนรู้อื่น|สาระที่ 3 ภาษากับความสัมพันธ์กับกลุ่มสาระการเรียนรู้อื่น]]
**มาตรฐาน:** [[00_มาตรฐาน ต 3.1|มาตรฐาน ต 3.1]] (ใช้ภาษาต่างประเทศในการเชื่อมโยงความรู้กับกลุ่มสาระการเรียนรู้อื่น และเป็นพื้นฐานในการพัฒนา แสวงหาความรู้ และเปิดโลกทัศน์ของตน)

**สาระการเรียนรู้แกนกลาง:**
- คำศัพท์ที่เกี่ยวข้องกับกลุ่มสาระ
- การเรียนรู้อื่น คำศัพท์ที่เกี่ยวข้องกับกลุ่มสาระ การเรียนรู้อื่น
- คำศัพท์ที่เกี่ยวข้องกับกลุ่มสาระ
